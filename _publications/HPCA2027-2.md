## Abstract

Modern computing systems are rapidly evolving toward large-scale multi-chiplet architectures, where modular architectural simulation has emerged as a promising approach. However, synchronization in parallel simulation among independently executing simulator processes remains the fundamental scalability bottleneck. Existing approaches either synchronize frequently or obtain correct communication timing through trace collection, offline network analysis, and replay. This paper proposes **FCS**, a frontier-based synchronization model that replaces replay-based timing correction with commit-time causal ordering. An event changes simulated state only after a synchronization frontier certifies that no earlier causally relevant event can still appear; replay is therefore removed from the normal correctness path. FCS first realizes this rule in a centralized configuration, independent of communication locality. It then adds a hierarchical synchronization tree as an optional locality-aware optimization that distributes the same commit rule without changing its correctness semantics; when locality is weak, FCS falls back to centralized frontier synchronization. Experimental results show that FCS reduces simulation time by an average of 41.64% over LEGOSim with negligible error (0.033%) across eight workloads. These results demonstrate that frontier-based commit-time ordering and locality-aware scaling improve the efficiency of modular architectural simulation.
